# 🎮 Assignment Angry Bird

This repository contains a small collection of Python mini-games built for learning and fun. It includes a Pygame-based Angry Bird style game and a classic Tic-Tac-Toe console game.

---

## 🚀 Features

- Beginner-friendly Python scripts
- Simple game logic with easy-to-follow code
- One graphical game using `pygame`
- One terminal-based strategy game for two players

---

## 📁 Included Games

| Game | File | Description |
| :--- | :--- | :--- |
| **Angry Bird Game** | `AngryBirdGameNavneet.py` | A side-scrolling flap-and-dodge game with obstacles, scoring, and sound effects. |
| **Tic-Tac-Toe** | `TicTacToe.py` | A classic 2-player Tic-Tac-Toe game played in the terminal. |

---

## ⚙️ Prerequisites

Make sure you have Python 3 installed on your system.

```bash
python --version
```

For the Angry Bird game, install `pygame` if it is not already available:

```bash
pip install pygame
```

---

## ▶️ How to Run

From the project folder:

```bash
python AngryBirdGameNavneet.py
```

```bash
python TicTacToe.py
```

Note: The Angry Bird game uses `angry-bird-icon.png` and `song.mp3`, so run it from the repository root so the asset files are found correctly.
