# 🎮 Python Mini Games

A collection of fun, lightweight, and beginner-friendly mini-games built using pure Python. This repository is designed for hobbyists, students, and anyone learning Python who wants to explore basic programming logic, loops, conditionals, and standard libraries through interactive projects.

---

## 🚀 Features
* **Beginner-Friendly:** Written with simple, readable Python code—ideal for learning fundamentals.
* **No Heavy Dependencies:** Most games run straight out of the box using Python's built-in libraries (like `random`).
* **CLI & GUI Options:** Includes both terminal/console-based games and graphical interface projects.
